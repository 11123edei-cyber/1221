# Подсчёт комнатных растений

Локальное веб-приложение на Flask и YOLOv8: подсчитывает растения
в горшках на фотографии, показывает результат и сохраняет историю.
Историю можно скачать в PDF и Excel.

## Требования

- Python 3.10 или 3.11.
- Интернет для установки зависимостей и первой загрузки модели.
- Доступ на запись в папку проекта.

Видеокарта не обязательна — поддерживается работа на CPU.
PyTorch устанавливается автоматически как зависимость Ultralytics.

## Структура проекта

```text
plant-counter/
├── app.py                 # Сервер, распознавание, база данных, экспорт
├── requirements.txt       # Зависимости Python
├── README.md              # Инструкция
├── templates/
│   └── index.html         # Веб-интерфейс
├── static/
│   └── result.jpg         # Последнее обработанное изображение
├── history.db             # История обработок
└── yolov8n.pt              # Веса модели
```

`static/` и `history.db` создаются автоматически.
`result.jpg` появляется после успешной обработки.
Если `yolov8n.pt` отсутствует, модель скачивается при первом запуске.

## Установка и запуск

Откройте терминал в папке проекта.

### Windows

```powershell
Запустить start.cmd
```

### Linux / macOS

Используйте Python 3.10 или 3.11:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Откройте http://127.0.0.1:5000 в браузере.

Первый запуск может занять больше времени из-за скачивания модели.
Для остановки сервера нажмите `Ctrl+C`.

## Использование

1. Выберите фотографию JPEG или PNG размером до 10 МБ.
2. Нажмите «Запустить обработку».
3. Дождитесь количества обнаруженных растений и изображения с рамками.
4. Для скачивания всей истории нажмите PDF или Excel.

Каждая успешная обработка создаёт отдельную запись в базе данных,
даже если растений не обнаружено или фотография загружена повторно.
Дата и время записываются в локальном времени сервера.

## Экспорт

| Адрес | Результат |
|---|---|
| `/export/pdf` | Файл `plant_history.pdf` |
| `/export/excel` | Файл `plant_history.xlsx` |

В отчёты включается вся история: ID записи, дата и время,
количество растений. Изображения в отчёты не включаются.

PDF использует английские заголовки и встроенный шрифт,
поэтому установка дополнительных шрифтов не нужна.
Excel использует русские заголовки.

Если история пустая, отчёты содержат только заголовки.

## Особенности и ограничения

- Используется YOLOv8n, класс COCO `58` — `potted plant`.
- Порог уверенности обнаружения — 0.25.
- Результат является оценкой: возможны пропуски и ложные обнаружения.
- Приложение считает объекты на фотографии, а не уникальные растения
  в квартире. Оно не устраняет повторы между фотографиями.
- Последнее обработанное изображение перезаписывает `static/result.jpg`.
- История хранится в `history.db` между перезапусками.
- Интерфейс рассчитан на локальное использование одним пользователем.
- Авторизация отсутствует. Встроенный сервер Flask не предназначен
  для публичного размещения.

Для резервного копирования истории остановите приложение
и скопируйте `history.db`.

## Проверка после установки

1. Загрузите фотографию — должны появиться количество и изображение.
2. Скачайте PDF и Excel — в обоих должна быть новая запись.
3. Загрузите повреждённый файл с расширением `.jpg` —
   должно появиться сообщение об ошибке.
4. Перезапустите приложение и скачайте историю —
   предыдущие записи должны сохраниться.

## Возможные проблемы

### OpenCV: отсутствует `libGL.so.1`

Для Debian/Ubuntu:

```bash
sudo apt-get update
sudo apt-get install libgl1 libglib2.0-0
```

### Не скачивается модель

Проверьте подключение к интернету. Для работы без интернета заранее
поместите официальный файл весов `yolov8n.pt` в папку рядом с `app.py`
и установите зависимости.

### Ошибка `TemplateNotFound`

Убедитесь, что HTML-файл расположен именно в
`templates/index.html`, а не рядом с `app.py`.
